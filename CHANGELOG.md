# Changelog

Newest first. One `## YYYY-MM-DD` heading per day, one `- ` bullet per change. A bullet is one player-facing sentence that says what changed in the game, with no file names, code names or em dashes. The game reads this file at build time and shows the bullets a newer build has when it offers a reload, so every change that lands in main adds its bullet here.

## 2026-10-30

- The DNS, VPN, storage and mail software now have their own websites in the Browser, each in the look of its year, and the Download page says what the server becomes after the install.
- A clean shutdown now takes a few minutes while the operating system halts, and a reboot waits for that halt before it boots; holding the power button, pulling the plug or a hard power off still cuts the server at once.
- The USB stick and the virtual machine's ISO now install an operating system, Debiant GNU/Lunix or Windoors Server, and software is installed afterwards from the machine's console or over ssh with the commands its website gives.
- A VMwhere cluster can buy the App Suite for 25 euros a month, which deploys a virtual machine with its operating system and software in one step.
- A location that has not opened yet is grayed out in the Locations app and its sidebar, with a countdown in days and then hours until it is ready.
- Messages about addresses now say IP address.
- A new company starts without a website: build a free HTML site in Marketing under Channels in three days, buy a domain, pick rented or own hosting and launch it.
- The site Admin page is gone; once the site is live, Marketing gains a Products section where SSL sits under web hosting as its add-on.
- Datacenters now rent space as a rack, a cage or a private suite, and rack positions are gone; a location you rented as positions is now a cage.
- Flat-rate power contracts are now offered for your own racks in cages and suites.
- The Delete button in confirmation dialogs is red again on the early desktop themes.

- Time runs faster in companies with many services.
- The Browser has a home icon that opens the Yahoy! start page, a directory of every site in the game by category, including your own consoles, which replace the Sponsor-Bored and console bookmarks.
- Every operating system and software has its own website with its features, prices and the commands to install it, and the sites change their look over the years.
- The first time you open the game, a notice explains that Backbone is in early access and links to GitHub and Discord for feedback.
- A server's actions now sit in one row of tiles without section headings, and its remote access card only shows when a console is attached.
- A new Applications app lists every installed app; right-click any app there or in the dock to remove it from the dock, keep it in the dock, or put a link to it on the desktop.
- SSL certificates can go on your website and are resold through your registrar partner: new web hosting customers add one to their order, and customers who ask for the padlock buy one after your SSL reply.
- Every server and virtual machine now runs an operating system, Debiant GNU/Lunix or Windoors Server, and every machine on Windoors bills its 15 € license each month.
- Software on one machine can no longer share a network port, and HyperVee and TCAdmen only install on a machine running Windoors.
- The welcome intro now says you start with 3,500 € of savings and an empty rack, matching the money you actually have.
- Email settings now warn that a free Notmail address looks unprofessional to business customers.
- The Email app now takes on the look and logo of your mail provider or support desk, with the logo shown in a bar above the inbox.
- Email settings open as a small sheet over the app, where you pick Notmail, a hosted provider or your own mail server from one list.
- Your computer now starts on an older Pear OS look, and each new Pear OS release offers a Software Update that restyles the desktop to match its era.
- The New VM bar in a hypervisor console now also creates VMs with game server or mail software, not only web hosting panels.
- At the server you now only press the power button, whose icon shows whether the server is on; unplug a cord from its power supply instead of using the old unplug, hold and reset buttons.
- Your own virtual machines install software from their console: the Console tile in the VMs app or the Console button on the hypervisor's page opens it, Load installer ISO boots the same installer as on a server, and the Software tiles are gone from the VM page.
- The Shop sidebar opens and closes server lines and switch layers with an arrow, Software sits on its own at the top, a list view sits next to the grid, and both now show only CPU, RAM and storage, with everything else on a details page.
- CPUs now last about 7 years before they start to fail more often, instead of 15.
- Game servers are now sized and priced like real ones, starting at about €29 a month in 2005 and €12 today, while VPS and cloud servers cost more in the early years.
- Selling DNS, VPN and storage now needs DNS, VPN or storage server software, installed on a server or in one of your VMs, instead of only a hypervisor.
- Nine new programs join the software catalog: Bound, PowerDNZ and Knut DNS for DNS, OpenVeePeeN, Sysko AnyConnekt and WireGuarded for VPN, and vsFTPeed, OwnClod and MinnIO for storage.
- The Components list only sends remote hands, and only at a datacenter; to work on a server yourself, open Change parts, which now also opens on a running server for hot-swap parts.
- Installing a part with remote hands works again instead of saying the slot does not exist.
- Starting hand work on a server skips time until the work is done, and a notification says when it finishes.
- Attackers can no longer break into a panel host that is switched off, failed or has its panel VM stopped.
- Cleaning up a hacked panel host now restores every site that has a backup of its own or of the panel VM it runs in, and the site Clean up button counts both the same way.
- Domains are now bought on registrar websites in the Browser, where a search suggests names across every ending with the price of each.
- Your reseller contract, tier and domain list moved from the Network app to your registrar's website, and Network has a new icon.
- A customer who accepts a quote when no server has room now goes elsewhere right away, instead of waiting and signing hours later.
- Software now installs from the server's screen: press F11 during POST, boot from the USB stick and pick from the installer's catalog, which shows the array, what the disks hold and the install's progress. The Software tab and the Add Software entry are gone from servers.
- Reinstalling over software with customers on it lists what dies and needs the server's hostname typed; the data is lost like on a dead array. The installer also erases a server to bare metal, and a reset or a pulled plug during an install leaves the disks empty.

## 2026-10-29

- cPanic, Pleskit, DirectAdmen, HyperVee and VMwhere can install their updates automatically at night once their vendor offers it, turned on per cluster in its console or the Software menu.
- The News app now announces new network and power gear, server types, home lines, port speeds, help desks, trainings, software features and free SSL certificates on the day they arrive.
- Every 1 January the News app lists the new releases of the software you run, including a new PHP version when you run a hosting panel.
- The Getting started step for company email now names the Support app once a support desk is installed, matching the app in your dock.
- Move servers on a rack takes several servers to a datacenter in one go: drive them yourself for the fare and rack them on arrival with no shipping or remote hands bill, or have a friend take them from home.
- Disk and RAM meters on locations and nodes now show the used amount in its own unit, so 2 GB of 1 TB no longer reads as 2 TB.
- When you are at the datacenter, the server's power and plug buttons now work at once instead of calling remote hands, and from afar you can send a friend to press them.
- The Browser has a new site, Sponsor-Bored, bookmarked from the start, where you post an offer for a free or half-price server, and clans, LAN parties, fan sites, student projects and mirrors apply by email; a running sponsorship adds awareness and leads every month, but some of the applicants misuse the server or drop your banner.
- An open offer on Sponsor-Bored can be withdrawn, which closes its waiting applications and keeps running sponsorships going.
- Sponsor-Bored lists the sponsoring requests of community events with their audience, needs and deadline, and you can answer one with a free offer or with 50% off, which the community takes or turns down a day later.
- Rack positions at Hetzler and the smaller budget datacenters can take a flat-rate power contract of 2 × 10 A or 2 × 16 A for a fixed monthly price, which sets the rack's breaker limit.
- From 2008 SuperMacro and Dwell sell the Twin 2U, a chassis with four server nodes that share two power supplies and a fan wall, so a failure of the shared parts takes all four nodes down, and used Twin lots show up on the used market.
- Customers move between any two datacenters over the internet, and Move to on a server ships it with its customers to another location, with new addresses for the services and a maintenance window announced to the customers.
- The Shop now switches between New and Used at the top, lists only real manufacturers including the CPU and GPU makers, and groups server lines and switches under expandable classes with Software as its own class.
- A customer who wants to cancel can be offered 50% off the next month, a free month, 20% off for 3, 6 or 12 months, a free upgrade, a move to a better server or an apology with a fix promise, each shown as a card with its cost and how likely it is to work, and customers at any happiness can be kept by a strong enough offer.
- Sending an upgrade offer locks its price and buttons until the customer writes back a few hours later, and a counter-offer brings the ticket back to your inbox.
- An upgrade request now opens in Support with its quote, the same way an order email does, and customers only ask to upgrade services that can grow; the reply that offered more resources without a price is gone.
- Sponsoring requests only ask for products you sell on your website, and four new events can write in: a school coding club, an animal shelter, a game jam and an open data hackday.
- Customers now ask how-to questions that fit what they run and how long they have been with you: newcomers ask about uploads, Outlook and name servers, server customers about SSH, and long-standing customers about PHP versions, a second domain or mail on a new phone.
- The Documentation skill unlocks the Knowledge base app in the Pear Store, which answers three in ten basic setup questions before they reach your inbox and shows how often each article was read.
- Customers send most of their how-to questions in their first months while they set up, and long-standing customers only write in now and then.
- The dock shows a count of open tickets, unpaid invoices and failed parts from the start, and the Dock badges upgrade is gone from the Pear Store.
- New reviews only send you a notification once Marketing campaigns unlocks the Reviews section where you can read them.
- The Security app lists every compromised host, including virtual machine clusters, game panels and the mail host, with a Clean up button that works without Monitoring.
- The Security app now sits in the dock from the start, so you can clean up a compromised host without waiting for an alert.
- Loans moved from the Bank app into a new Loans page in Finance, and loan alerts open it directly.
- Marketing basics now opens the Reviews and Community sections in Marketing, and new reviews only send you a notification once you can read them there.
- Event organisers only ask you for sponsoring once you have learned Marketing basics.
- A VM or game server stuck on a switched-off server whose cluster's control plane is down can be recovered to a server of another cluster in the same location by remote hands, by you or by a friend.
- Restoring a defaced customer site now needs a backup of it, and without one you can only tell the customer to rebuild it from their own copy, which costs happiness.
- The sheet that opens after a training starts with a Now available page that checks off everything the skill unlocks and what you can do with it.
- The Used tab has listings from the first day: servers and network gear sold since before 2005 turn up on eBuy, WebHostingTalc and Telegrump right away, one to three years old.
- Every server has a screen now: a Console tile on managed servers and the controller's page open it in its own window, a KVM opens it from its page, and clicking the blue console end on the back of a server in the rack plugs in a monitor on the spot.
- The RAID level moves from the server page into the BIOS setup on that screen, entered with Del during the boot splash or at the firmware prompt, and a server left in the setup stays down until you leave it.
- The Backbone menu has Report an issue, which opens a new GitHub issue with your game build filled in.
- The Marketing app opens on Channels once you learn Marketing campaigns, its Domain page has proper margins, and the skill sheet lists the six sections the skill adds.
- The Backbone menu links to the new Discord server, where you can chat, share screenshots, request features and report bugs.
- The browser tab shows the new Backbone logo.
- A customer whose services all kept their SLA uptime through a month gains a little happiness at the billing date, so steady service slowly builds loyalty.
- Replies, order steps and other hand work now land at the minute they are done instead of at the next full hour, a server boots in three minutes and a new domain shows as registering for two.
- A custom order now sends the customer three emails, the quote, the confirmation and the notice that everything is live, instead of one per step.
