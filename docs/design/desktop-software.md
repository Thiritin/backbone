# Desktop software

The player's computer runs a macOS-like system, so every desktop program installs the way it does on a Mac. Websites only sell or offer the download; nothing installs from a website.

## Installing

1. The player downloads the program on the vendor's website in the Browser. A free program (FileGorilla) downloads at once; a paid desktop program (bookkeeping) is paid first. The download takes as long as the player's line needs for the file's size.
2. The finished download appears in Finder under Downloads as a disk image (`.dmg`), named after the program and its release, for example `FileGorilla_3.5.3.dmg`.
3. The player drags the disk image onto Applications in Finder's sidebar or into the Applications folder. The context menu entry "Move to Applications Folder" does the same. Opening the file does not install it.
4. The program appears in Applications and in the dock.

The disk image stays in Downloads after installing, so a program can be installed again without a new download.

## Replacing a program

Only one bookkeeping program runs at a time. Installing a second one asks the player to confirm that it replaces the current one. The books themselves stay; the old program's edition, seats and monthly fee end.

## Uninstalling

The Trash sits at the right end of the dock and in Finder's sidebar. Dragging a program from Applications or the dock onto the Trash, or choosing "Move to Trash" in its context menu, uninstalls it. Bookkeeping asks for confirmation first; other programs go at once. The system's own apps (Browser, Finder, Chat and the like) cannot be moved to the Trash.

Uninstalling bookkeeping keeps the books. Installing a program again later starts with no extra seats.
