# Changelog

Newest first. One `## YYYY-MM-DD` heading per day, one `- ` bullet per change. A bullet is one player-facing sentence that says what changed in the game, with no file names, code names or em dashes. The game reads this file at build time and shows the bullets a newer build has when it offers a reload, so every change that lands in main adds its bullet here.

## 2026-10-29

- Servers and virtual machines show their power actions as square tiles, and a custom order shows the CPU, RAM and storage load of the cluster or server you pick to set it up on.
- Each location shows what its cluster servers have booked next to what they use right now.
- OpenVeeZee and Proxmocks split cores, so a VPS customer can buy 0.8 of a core, while OpenStash, VMwhere and HyperVee book every VM in whole cores.
- Locations has a sidebar with every site grouped by region and the racks of the open site, and each site splits into Floor, Cabling, Storage, Clusters and Internet line tabs.
- The first-hour design note describes the current start, and the datacenter space docs match the rack shares the game rents.
- The Shop filters servers by form factor, cores, RAM and disk type across all manufacturers.
- The game offers a reload when a newer version is online and lists what changed.
- Important notifications pause the game and open a sheet with Open and Continue.
- Notifications have types per app that can be switched off, and a News app reports new hardware, software and market changes.
- The company website runs on a rented host or one of your own panel hosts, and its design ages until you redesign it.
- Going online needs a registrar contract and your own domain, and company email comes from a provider or your own mail server.
- Panels show which can import web spaces and cluster; moving a web space between panels is a hand task with a short cutover.
- Installed software has versions and vulnerabilities; Nagiosaurus monitoring lists them and updating is a task with downtime.
- Customer sites run a CMS that gets outdated; you can notify customers and sell one-off or managed updates.
- Game server panels TCAdmen, MultiKraft and Pterodaktyl host game servers.
- A critical vulnerability left open can lead to a breach with a ransom demand and a data protection fine.
- Servers, VMs and services have hostnames, and tickets name the service by its hostname.
- The Browser opens your company site with an Admin page, customer sites, server consoles and management pages.
- Servers with a management controller offer graceful shutdown, reset and power cycle; a pulled plug can corrupt data that needs recovery.
- The Terminal connects to servers and runs ping and traceroute along the real network path.
- Searchlight opens with Ctrl+K once bought from the Pear Store.
- Servers are built from parts in slots; the Shop sells bare chassis, presets with extras and single parts; a powered-off server can be opened to see and swap parts.
- Part prices follow the years, with the 2018 and 2026 memory spikes; GPU cards and a GPU server line arrive from 2011.
- Hardware has end of sale and end of support years; routers, bigger UPS units and switched PDUs are in the Shop.
- Deliveries take days, and a cheap tower server stands on a basement shelf.
- Support is now Email in the look of your mail provider until you buy a support desk such as Zendusk or Freshdusk.
- Overprovisioning is always allowed; only disk is a hard limit, and overbooked servers slow down or freeze.
- Getting started names where each step is done and opens that place; the Checklist app is gone.
- The web design and order form can be set up from the Admin page from day one.
- The Security app lists software with urgent vulnerabilities and offers the update without monitoring.
